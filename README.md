# Persona Studio – User Persona Development Platform

## Overview

Persona Studio is a web-based User Persona Development platform designed to help UX designers, students, researchers, product managers, and marketing teams organize user research and develop structured user personas.

The project provides a clean, professional interface for creating personas, exploring user characteristics, comparing user segments, and reviewing research insights.

The application is designed with a focus on usability, visual consistency, and an organized user experience.

## Features

- **Dashboard:** Overview of personas, projects, and research activities.
- **Persona Creation:** Guided interface for defining user characteristics, goals, motivations, needs, and pain points.
- **Persona Profiles:** Structured presentation of persona information and behavioral characteristics.
- **Persona Library:** Interface for browsing and organizing personas.
- **Project Management:** Screens for organizing persona development projects.
- **Research and Insights:** Interface for presenting research findings and user observations.
- **Persona Comparison:** Side-by-side comparison of different personas.
- **Reports and Exports:** Interface for reviewing reports and export options.
- **Authentication UI:** Sign-in, account creation, password recovery, and password reset screens.
- **Theme Customization:** Design system based on three primary brand colours.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Responsive web design principles

## Design System

The interface uses a professional three-colour theme:

| Colour | Hex Code | Purpose |
|---|---|---|
| Indigo | `#4F46E5` | Primary actions and navigation |
| Teal | `#0F766E` | Secondary actions and highlights |
| Amber | `#F59E0B` | Accent elements |

The design also uses neutral backgrounds, readable typography, consistent spacing, and reusable interface patterns.

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension for Visual Studio Code (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/persona-studio.git
   ```

2. Open the project folder:

   ```bash
   cd persona-studio
   ```

3. Open the folder in Visual Studio Code.

4. Launch `index.html` using Live Server, or open the HTML file directly in your browser.

No package installation or build process is required for the static HTML prototype.

## Current Project Status

Persona Studio currently provides an integrated frontend prototype containing the main application screens.

The interface is intended as a foundation for further development. A complete production implementation may require additional work on:

- Persistent data storage
- Complete persona creation, editing, and deletion workflows
- Secure authentication and authorization
- Functional PDF and CSV exports
- Fully implemented theme customization
- Comprehensive validation and error handling
- Automated and end-to-end testing

The presence of a screen does not necessarily mean that its functionality is fully implemented.
